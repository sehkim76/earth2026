# 영주성 내정·4자원·일꾼 채집·병력 (2026-11-27)

사용자 결정: 기존 영토 영주성을 본거지로 통합 / 병력 수를 전투력에 반영 / 영향력은 금으로 전환.
장르 공통 구조(성 안 건물·자원지·일꾼·병력)를 쓰되 이름·그림·화면은 이 게임 고유로 만든다 (특정 게임 외형 복제 금지).

## 데이터
- 금: `MissionUser.score` (옛 영향력, 잔액 그대로 금). 상한 200,000. 함수 이름(spend/grantInfluence)은 호환 유지.
- 석재·나무·철광석, 건물·연구·병력·일꾼: 새 테이블 `TerritoryCity.data` (사용자별 1행). 잠금 `city:<userId>`.
- 코드: 순수 `src/lib/city.ts`, 서버 `src/lib/city-server.ts`, API `GET /api/city`·`POST /api/city/action`.

## 본거지 영주성
- 영주성이 하나도 없으면 시작 시 「영주성을 세울 곳을 정하세요」 안내 → 기존 축성 배치로 세움.
- 첫 영주성(본거지)은 계급·승수·비용 면제. 영주성이 없는 동, 영주가 있는 동 안, 다른 성과 200m 이상.
- 본거지 = 이번 시즌 내 영주성 중 가장 먼저 세운 것. 빼앗기면 내정은 유지되고 새 영주성을 세우면 그곳이 본거지.

## 건물 (최대 Lv.10, 한 번에 1개 공사, 본관 레벨이 상한)
본관·창고·일꾼 막사 / 벌목장·채석장·제철소·주조소(시간당 생산) / 학당(연구) / 병영·궁술장·마구간·마탑(병종 훈련).
비용 레벨마다 ×1.55, 시간 ×1.6(최대 2시간). 시작: 본관·창고·막사·벌목장·채석장·제철소 Lv.1, 석재·나무 500, 철 200.

## 연구 (최대 Lv.5, 학당 레벨까지)
생산 개량(+8%/Lv) · 채집술(+10%) · 길잡이(일꾼 이동 +10%) · 무예 단련(병력 공격 +5%) · 갑주 제작(병력 체력 +5%).

## 자원지·일꾼
- 약 1.1km 격자 칸마다 0~2곳, 6시간마다 새로 생성(결정적, 서버·화면 같은 함수). 나무 32% · 석재 28% · 철광석 25% · 금 15%, Lv.1~3.
- 지도 확대 14 이상에서 표시 → 「일꾼 보내기」. 영주성에서 4km 이내, 일꾼 부대 수 = 1 + 막사 Lv/3, 1회 운반 300 + 250×Lv.
- 이동 4m/s, 채집 1.5/초 (연구 보정). 도착→채집→귀환은 서버가 시간으로 정산. 불러들이면 채집한 만큼만 가져옴.
- 일꾼은 도로로만 다닌다: 파견 시 서버가 무법자·부대와 같은 도로 그래프(`findServerRoute`)로 영주성→자원지 경로를 찾아 `GatherJob.path`에 저장(솎아서 최대 300점). 이동 시간 = 도로 길이 / 속도, 도로 편도 최대 7km. 채집 지점은 자원지 옆 도로 끝. 경로를 못 찾으면 파견 거부. 가는 중 불러들이면 온 길을 되짚어 돌아온다. 경로는 클라이언트에서 받지 않는다.
- 지도 표시: 조선 농부(상투·흰 머리수건·흰 무명 저고리·행전·짚신) 일꾼. 병사·무법자와 같은 8프레임 스프라이트 시트(`public/markers/farmer_*_sheet.png`, 생성 스크립트 `scripts/build-farmer-sprites.mjs`). 이동 땐 곡괭이·도끼를 메고 걷고, 금·석재·철광석은 곡괭이질, 나무는 도끼질, 귀환 땐 지게에 짐(가마니·장작)을 지고 걷는다. 진행 방향으로 좌우 반전.
- 매장량 소진은 사용자별로 계산(다른 사람과 경쟁 없음, 1차 단순화).

## 병력
- 보병·궁병·기병·마법병을 군사 건물에서 훈련(1회 최대 30×건물 Lv) → 예비 병력 → 성 안 「병력」에서 지휘관(영주·부대)에 배치.
- 지휘관 병력 상한 = 60 + 30×(본관 Lv-1) + 20×(지휘관 Lv-1).
- 전투: 병력 1명당 체력·공격력 가산(보병 0.12/0.02, 궁병 0.07/0.035, 기병 0.1/0.033, 마법 0.06/0.045) × 연구 보정. 지휘관 병종(상성)은 그대로.
- 손실: 쓰러진 칸 50%, 살아남은 칸은 잃은 체력 비율의 30%. 공격·수비(대인·성주) 모두 전투 뒤 각자 `city:` 잠금으로 반영.
