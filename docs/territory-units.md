# 영토전 부대 기획

영토전에서 기존 “하인” 용어를 “부대”로 통일한다. 부대는 지도 위 병사 마커로 표현하며, 완료된 훈련 부대는 `soldier_idle_01.png`~`soldier_idle_08.png`를 순환 표시한다.

## 부대 훈련 및 모집

- 평민 이상부터 부대를 훈련할 수 있다. 계급별 보유 한도는 평민 1, 기사 2, 귀족 3, 영주 5명이다.
- 한 번에 하나만 훈련한다. 훈련 중인 부대는 보유 한도에 포함된다.
- 훈련 시작 시 영향력 50을 차감하고, 30분 후 부대가 완성된다.
- 훈련 시작 시 플레이어가 직접 보유한 활성 성 중 훈련 장소를 선택한다. 활성 보유 성이 없으면 훈련할 수 없다.
- 부대의 훈련 위치와 본부는 선택한 성의 서버 저장 좌표로 결정한다. 플레이어의 현재 GPS나 최근 GPS 기록은 요구하지 않는다.
- 이름은 선택 사항이며 최대 12자다. 비워 두면 “부대”로 생성한다.
- 완성된 부대는 선택한 성에 배치된다. 완성 시점에는 `field` 상태가 되어 지도 병사 마커로 표시된다.
- 완료 시각은 서버가 보관한다. 훈련 목록을 조회하면 만료된 훈련이 완성 상태로 전환되며, 화면은 훈련 중 15초 간격으로 목록을 새로 고친다.

## 기존 부대 규칙

- 부대 상태는 훈련 중, 야전, 주둔, 사망이다. 이동·정찰·공성·수성·입성은 야전 부대가 수행하고, 주둔 부대는 조작할 수 없다.
- 부대 행동에는 행동력 조건이 없다. 이동 거리·정찰·공성·수성·입성 모두 행동력을 소모하지 않는다.
- 계급별 보유 수, 전투력, 주둔 효과 및 사망 후 부활 규칙은 기존 영토전 부대 규칙을 유지한다.

## 호환성

- 새 데이터는 `MissionUser.data.units`에 기록한다. 기존 계정의 `data.servants`는 읽을 수 있도록 유지하고 두 필드를 함께 기록한다.
- 기존 `/api/servants/*` 경로와 응답/요청 키는 구버전 클라이언트 호환 별칭으로 남긴다. 신규 구현에서는 `/api/units/*` 및 부대 명칭을 사용한다.
- 저장된 구 데이터에 남아 있는 `actionPoints`/`stamina` 값은 읽을 때 무시하며, 새로 기록하지도 반환하지도 않는다.
